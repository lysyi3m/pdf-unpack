# Changelog

Notable changes in each App Store release, newest first. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## 1.3 — 2026-10-09

### Added

- iOS: PDF Unpack runs on iPhone and iPad. Open a PDF from Files or the share sheet, preview its
  embedded files with Quick Look, and save or share them. (#26)

### Changed

- Opening reads the PDF under file coordination, and Save All coordinates its writes, so files
  from a file provider open and save reliably. (#26)
